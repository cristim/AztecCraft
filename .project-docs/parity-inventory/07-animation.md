## Evidence record

- Documentation: Maya 2027 help, read on 2026-10-31 under the `cloudhelp/2027` paths below: [Animation hotkeys](https://help.autodesk.com/cloudhelp/2027/ENU/Maya-KeyboardShortcuts/files/GUID-0639ADA0-EBE5-4703-A874-92C80E4A0516.htm), [Playback Controls](https://help.autodesk.com/cloudhelp/2027/ENU/Maya-Basics/files/GUID-277ADCBF-6277-4B32-81E0-AEB6D081153F.htm), [Use the animation controls](https://help.autodesk.com/cloudhelp/2027/ENU/Maya-Animation/files/GUID-D3F23141-7B14-4DF3-91AB-25340F0BB2B7.htm), [Set keys](https://help.autodesk.com/cloudhelp/2027/ENU/Maya-Animation/files/GUID-7DE56A30-EEB4-4FDE-B4C4-6E53F4755822.htm), [New Scene Options](https://help.autodesk.com/cloudhelp/2027/ENU/Maya-Basics/files/GUID-8F961875-1D41-4C52-9CD5-B90DE75C546C.htm), and the [setKeyframe](https://help.autodesk.com/cloudhelp/2027/ENU/Maya-Tech-Docs/Commands/setKeyframe.html) and [playbackOptions](https://help.autodesk.com/cloudhelp/2027/ENU/Maya-Tech-Docs/Commands/playbackOptions.html) commands. The pages state no release in their text; their help links name 2027.
- Scope: documented behaviour of those pages only. No Maya numerics are compared (#5). Statuses describe documentation conformance, not Maya parity.
- Native visual check on 2026-10-31: a debug `mcp` build on Linux under KDE Wayland, at the default window size, driven through `--mcp-stdio`. It showed the row, key ticks at frames 1, 24 and 48, the cube following linear values at frames 12 and 20, playback, and a deleted key leaving the ruler. A later run the same day, in a private `kwin_wayland --virtual` session with fake input at 1600 by 1000, drove real input: Time Slider click and drag, S, Alt+comma, Alt+period, comma, period, Alt+V, Esc, the transport buttons, the Time field and Esc abandoning it, and S typed into the field adding no key, each confirmed through `inspect_scene`. An 800 wide session showed the row wrapping with all controls visible. Delete Key was clicked only on a frame with no key. Screenshots are not distributed. Headless coverage is in `src/app/features/timeline/tests.rs`.
- Fixtures: synthetic in-test scenes only.
